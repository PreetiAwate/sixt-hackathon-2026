# ProofGuard — Project 1

Read **START_HERE.md** for the repaired, staged workflow. Existing `.env` and data are preserved.

- `bash setup_app.sh`: dependencies, no data download.
- `bash start_app.sh`: document review GUI, Baseline or shared ProofGuard backend.
- `python pg.py doctor`: live role capability checks (paid calls).
- `bash workflow.sh smoke`: two development documents, diagnostic only.
- `bash workflow.sh calibrate 40`: development calibration + declaration.
- `bash workflow.sh evaluate`: frozen public-test run + official scores.
- `bash run_hidden.sh INPUT OUTPUT`: strict calibrated submission entry point.

Decision model is optional and only active when explicitly configured. Evidence checks do not prove correctness. Uploaded arbitrary documents require human review. Live results remain unmeasured for this revision.
